## 🚀 Key Features

- **Interactive ML Showcase**: Highlights key production-grade data science & ML projects, complete with architecture breakdowns, tech stacks, and impact metrics.
- **Glassmorphic & Dark Theme UI**: Custom modern styling built with HSL color variables, smooth CSS transitions, dynamic micro-interactions, and high contrast accessibility.
- **Single-File Architecture**: Zero dependency build step (`index.html`) optimized for ultra-fast load times and instant GitHub Pages deployment.
- **Responsive Layout**: Designed for seamless viewing across mobile, tablet, and desktop viewports.

---

## 🛠️ Tech Stack & Systems Covered

- **Machine Learning & Modeling**: XGBoost, LightGBM, PyTorch, Scikit-learn, Explainable AI (SHAP, LIME), Time-Series Forecasting.
- **Data Engineering & Big Data**: PySpark, Apache Spark, SQL, Polars, Pandas, DuckDB, ETL / Streaming pipelines.
- **Frontend Presentation**: HTML5, Vanilla CSS3 (Custom Design Tokens, Flexbox/Grid, Animations), ES6+ JavaScript.
